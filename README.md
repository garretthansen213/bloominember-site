# Bloomin' Ember Website

Shop site for Bloomin' Ember: handcrafted lotions, room sprays, perfume & cologne from Grantsville, UT.

- `index.html`: single file with the logo built in
- `index-hosted.html` + `logo.webp`: version for a web host

## Before launch
- Edit the `PRODUCTS` list in the script (names, scent notes, prices, colors)
- Set `CHECKOUT_URL` to a Shopify / Square / Stripe checkout (until then, checkout emails the order)
- Replace placeholder email, Instagram and Facebook links
